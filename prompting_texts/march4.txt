## 🎯 Project: GlamAI — AI Makeup Try-On Platform

### Purpose
A web platform where users upload a bare face photo, select makeup products from any brand, and get an AI-generated result showing how that product looks on their face. No AR, no realtime — upload and get result. Target users: girls age 14-100.

### Core Flow
```
User uploads bare face photo
→ Gate 1: Face validation (face exists, front facing, good quality)
→ Gate 2: Makeup detection (reject if already wearing makeup)
→ Gate 3: Skin tone detection (classify fair/light/medium/tan/deep/rich)
→ User selects: Brand → Category → Product → Shade (multiple categories allowed, one brand/product/shade per category)
→ Prompt engine builds massive detailed prompt (brand DNA + category formula + shade science + skin tone)
→ gpt-image-1 generates result
→ For multi-category: chained generation (result of category 1 becomes input of category 2)
→ Result saved, job tracked
```

### Prompt Engine Architecture (Important Context)
```
build_prompt(category_slug, product_data) where product_data contains:
  brand_name, brand_slug, product_name, shade_name,
  hex_color, finish_type, coverage, prompt_supplement

Internally:
  1. get_brand_dna(brand_slug) → brand persona, finish signature, texture, skin tone approach
  2. _hex_to_rgb() → brightness + undertone + depth description
  3. _skin_tone_guidance() → skin tone aware instructions based on shade depth
  4. Category builder (e.g. _lipstick_prompt) → assembles full prompt
  5. GLOBAL_REALISM appended → prevents AI slop, cartoon, filter results

detected_skin_tone (from Gate 3) needs to be added as parameter — NOT YET IMPLEMENTED
```
